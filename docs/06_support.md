# Support

[cApStAn](https://www.capstan.be) provides support to both cAliper and OmegaT users through their [Helpdesk](https://helpdesk.capstan.be/).

## cAliper

Should you get stuck while working in cAliper, please register and create a ticket in cApStAn's [Helpdesk](https://helpdesk.capstan.be/).

## OmegaT

Likewise, should an OmegaT user have an issue or a question related to their task in OmegaT or any aspect not covered in the [OmegaT guides](https://capstanlqc.github.io/omegat-guides/en/), they should create a ticket in cApStAn's [Helpdesk](https://helpdesk.capstan.be/) as the fastest way to get help.
